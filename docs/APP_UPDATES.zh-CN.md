## 自动提示的时机

每个 Android 应用进程冷启动最多自动检查一次。切换应用、返回前台、Activity 重建、CarPlay 重新连接不会重新检查或重复弹窗；检查期间切到后台，结果只更新“关于”中的状态，不在返回后补弹。

“启动时自动检查更新”开关立即保存；关闭后手动检查仍可用。启动时关闭、之后再打开该开关，也不会把下一次返回前台当成新启动。手动点击“检查更新”是主动操作，可以再次发现并提示新版。

## 下载和安装

1. 发现更新后点击“使用系统下载”。应用把固定更新目录中的 APK URL 交给 Android DownloadManager，不再用应用内 HTTP 客户端下载 APK。
2. 系统负责后台网络传输、进度与完成通知。任务编号及目标构建会保存，应用进程结束不取消系统任务；下次启动重新关联，不重复提交同一任务。
3. “关于”中可打开系统下载列表。APK 位于应用专属外部下载目录，无需新增存储权限；车机是否提供下载列表界面取决于系统，可查看系统下载通知。
4. 下载完成后，通过应用“安装更新”入口安装前，会将完整文件复制到私有缓存，核对大小、包名、版本/构建编号、release 标志、Android 兼容性和固定签名；系统安装器仍负责最终安装校验。
5. 下载完成、返回应用和 CarPlay 重连都不会自动弹安装界面。需要主动点击“安装更新”；首次安装权限仍由系统界面确认。
6. 系统下载服务失败时，“关于”显示失败状态及可用的错误码，可重试、查看系统下载，或主动选择“使用系统浏览器下载”。不会退回原来的应用内 APK 网络下载。

若车机上的旧版下载流程不可用，先手动安装本次 APK。之后将新 APK 按 CI 原始文件名上传到更新目录，后续版本才能被发现；本轮没有代为上传服务器。
