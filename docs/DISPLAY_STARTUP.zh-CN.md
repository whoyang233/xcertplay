# 启动画面比例与显示兼容

适用于个人版 1.4.2B。上游 1.4.1/1.4.2 已在个人分支历史中合入；本次核对后保留其视频缓冲复用、首帧淡入、音质菜单、无线高性能和麦克风修复，将多显示区域切换改为明确的可选菜单，不重新引入已移除的网页服务和车辆 JSON 后端。

## 修正范围

1. **等待真实窗口尺寸稳定。** 首次布局可能先得到 1920×1080，随后系统栏占位使视频窗口变成 1920×978。旧的启动回调可能在尺寸更新任务尚未执行时使用旧值。本次只在窗口已布局、恢复且获得焦点、无待处理尺寸、同一前台窗口版本的尺寸稳定 500 ms 后开始新的握手；权限回调、返回前台和设置关闭也经过该检查。运行中的后台连接照常复用，不因这项等待主动断开。
2. **屏幕基准保留真实宽高配对。** 旧的宽、高独立取最大值，可能把横屏 1920×1080 和竖屏 1080×1920 组合成不存在的 1920×1920，改变物理尺寸换算。现在 API 30+ 使用最大窗口边界，API 28/29 使用真实显示指标；旧累计值不再作为启动输入。指标无效时使用实际窗口的一整对尺寸。物理长度固定对应设备长边或短边，旋转不会互相混用。
3. **默认单区域兼容。** 不把历史分屏/安全区域尺寸自动并入启动视频流；按当前稳定窗口、分辨率比例和当前安全区域协商。多区域模式显式开启后才恢复已保存区域，且先排除超过当前实际屏幕范围的尺寸，避免其他显示器或旧配置撑大协商包络。
4. **画面与触控使用同一比例。** 单区域也按已协商视频比例居中适配，布局变化期间不强制拉伸。非分屏、同方向且仍位于原协商窗口范围内的临时收缩保留连接，维持非全屏快速切应用的保护；真正分屏、旋转或超出原窗口时按需重新协商。黑边中开始的手势整段忽略；内容中开始的拖动可移动到边缘并正确释放。多区域沿用上游区域裁切及触控比例。

这些修正覆盖可复现的代码路径和配置问题；尚不能仅凭源码确定每辆车上报告的启动异常都是同一原因，仍需实车核对。

## 菜单

位置：「设置 → 显示与视频」。

| 设置 | 行为 |
| --- | --- |
| 当前窗口 → 协商分辨率 | 区分实际窗口和给 iPhone 的分辨率；多区域模式显示实际包络尺寸。 |
| 多区域快速切换（实验性） | 默认关闭。显式开启后复用上游已保存区域以减少部分窗口切换的重新协商；手机兼容性和区域覆盖决定效果。 |
| 恢复显示默认值 | 恢复渲染比例 1.0x、60 FPS、长边 200 mm 和单区域兼容模式。保留独立的安全区域编辑/重置入口。 |
| 渲染分辨率比例 | 0.3x–1.0x，改变给 iPhone 的像素数量，不是局部放大或裁切。 |
| 界面尺寸基准 / 基准长度 | 长边或短边及对应毫米数，影响手机决定的 CarPlay 布局；与分辨率比例区分。 |

上述草稿点击右上角「重启 CarPlay」保存并生效，关闭设置放弃。安全区域沿用原有编辑和重置行为。新的多区域选项默认关闭，不清除已有安全区域记录，之后仍可按需启用。

## 回归与实车核对

自动化覆盖系统栏最终尺寸到来之前禁止启动、重复尺寸通知不无限延后、快速切应用和旋转失效旧窗口版本、时钟倒退、横竖屏物理基准一致、无效指标回退、历史超大区域过滤、默认兼容和选项保存、黑边手势及释放，并检查新增菜单在 1080P 和 150% 字体窄窗口下的操作和截图。

实车建议先保持「多区域快速切换」关闭，必要时恢复显示默认值并重启 CarPlay，然后检查冷启动、显示系统栏、快速切应用、实际分屏/旋转、触控位置和导航音频。图标或文字仍过大/过小时，记录当前窗口/协商分辨率、界面尺寸基准和截图，以区分手机布局选择与画面拉伸。
